# 📈 Nifty 50 Stock Market Forecasting (2000–2035)

Nifty 50 data to forecast stock prices using four time series models

---

## 🔧 Tools & Technologies Used

- Python (Data Preprocessing & Modeling)
- Excel (Data Cleaning + Dashboard)
- Jupyter Notebook / VS Code
- Models: Prophet (Facebook's Open Source Forecasting Tool)

---

## 📈 Forecasting Target

- **Stock:** Nifty 50 Index
- **Period:** 2000–2035 (Forecast)
- **Columns Predicted:** Open, High, Low, Close

---

## ✅ Build steps

### Python Models
```bash
pip install -r requirements.txt
python nifty50_forecast.py
```
